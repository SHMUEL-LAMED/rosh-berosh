# rosh-berosh-ivr

שירות טלפוני עצמאי שמחבר את מערכת הסקרים "ראש בראש" לקו הטלפוני של ימות המשיח.

## למה זה שירות נפרד מהאתר?

ימות המשיח קוראים לכתובת שלך בכל הקשה של המתקשר ("webhook"), ואתה עונה להם מה
לעשות הלאה. הספרייה שאנחנו משתמשים בה (`yemot-router2`) שומרת את מצב השיחה
בזיכרון של תהליך Node.js אחד שרץ ברצף, כדי לאפשר לכתוב את כל תסריט השיחה כפונקציה
רגילה עם `await`. זה לא תואם לאתר שרץ על Cloudflare Workers (כמו האתר הראשי),
ששם כל בקשה מטופלת בנפרד בלי זיכרון. לכן השירות הזה חייב לרוץ במקום שמאפשר
תהליך Node.js קבוע - שרת VPS, Render, Railway, Fly.io וכו' (לא Vercel/Cloudflare
בפריסה הרגילה שלהם, כי גם שם כל בקשה נפרדת).

## התקנה

```bash
npm install
cp .env.example .env
# ערכו את .env - צריך להזין את כתובת אתר הסקרים שלכם
npm start
```

## משתני סביבה

- `SITE_API_BASE_URL` - כתובת הבסיס של אתר הסקרים "ראש בראש" (בלי סלאש בסוף),
  לדוגמה `https://rosh-berosh.example.com`. השירות קורא משם את
  `GET /api/catalog` ושולח את ההצבעה אל `POST /api/ballots` עם
  `channel: "phone"`.
- `PORT` - פורט מקומי (ברוב שירותי האחסון מוגדר אוטומטית).

כדי שקובצי הקריינות שמועלים באתר יועברו אוטומטית גם למערכת הטלפונית, יש להוסיף
ב־Cloudflare Worker סוד בשם `YEMOT_TOKEN`. הערך הוא טוקן הניהול של ימות המשיח.
אפשר להגדיר גם `YEMOT_API_BASE` אם המערכת נמצאת בשרת אחר; ברירת המחדל היא
`https://www.call2all.co.il/ym/api`.

## הגדרה בממשק הניהול של ימות המשיח

1. בכנסו לממשק הניהול של ימות המשיח ובחרו שלוחה (למשל השלוחה הראשית `/`).
2. הגדירו את סוג השלוחה כ-`api` (מודול API - תקשור עם מחשבים חיצוניים).
3. הגדירו `api_link` לכתובת שהשירות הזה רץ עליה, לדוגמה:
   `https://ivr.example.com/`
4. חשוב: אין להגדיר `api_hangup_send=no` (עבור ביצועי זיכרון תקינים בספרייה).

## איך זה עובד

1. מתקשר מתקשר לקו וימות המשיח קוראים לשירות הזה.
2. השירות משמיע תפריט ראשי קצר: לבחירת אלבומים מקישים 1, לבחירת שירים מתוך
   האלבומים שכבר נבחרו מקישים 2, ולבחירת זמרים מקישים 3.
3. בסיום כל חלק חוזרים לתפריט הראשי, בלי לאבד את הבחירות שכבר נעשו.
4. אחרי שכל החלקים הפעילים הושלמו, השירות שולח את ההצבעה לאתר
   (`voterKey` = מספר הטלפון של המתקשר, כדי
   למנוע הצבעה כפולה מאותו טלפון - בדיוק כמו שהאתר מונע הצבעה כפולה מאותו
   דפדפן).
5. כל הודעה ושם פריט ניתנים להחלפה בהקלטה אנושית דרך מסך "קריינות לקו"
   באתר. כשאין קובץ פעיל, המערכת משתמשת בהקראה אוטומטית.
6. משמיעים הודעת תודה ומנתקים.

## הערה חשובה על טקסט מוקרא

ימות המשיח דוחים (וזורקים שגיאה על) כל טקסט שיש בו את התווים: נקודה, מקף,
גרש, גרשיים, או `&`. כברירת מחדל בקוד הזה (`removeInvalidChars: true`) התווים
האלו פשוט **מוסרים אוטומטית** מהטקסט לפני השליחה, כדי שזה לא יקרוס. שימו לב
לכך אם תוסיפו הודעות טקסט חדשות.

## בדיקה מקומית בלי טלפון אמיתי

אפשר לדמות בקשות מימות המשיח עם `curl`, לדוגמה:

```bash
curl "http://localhost:3000/?ApiCallId=test1&ApiPhone=0500000000&ApiDID=0771234567&ApiExtension=1"
```

לתגובה הראשונה (תפריט) יהיה `val_1=1` בהקשה הבאה כדי לדמות הקשה על "1":

```bash
curl "http://localhost:3000/?ApiCallId=test1&ApiPhone=0500000000&ApiDID=0771234567&ApiExtension=1&val_1=1"
```

# ראש בראש

מערכת הצבעה למצעד מוזיקה, עם אתר ציבורי וקו טלפוני של ימות המשיח המשתמשים באותו מסד נתונים.

## תהליך ההצבעה

1. בחירת חמישה אלבומים.
2. בחירת שיר אחד מכל אלבום שנבחר.
3. בחירת זמר אחד עד שלושה.
4. אישור ושמירת הצבעה אחת לכל מזהה מצביע.

## רכיבים

- `app/` — אתר Next.js/Vinext ונתיבי API.
- `db/` ו־`drizzle/` — סכמת Cloudflare D1 והמיגרציה.
- `ivr-service/` — שירות Node.js רציף לקו ימות המשיח.

## פיתוח

```bash
npm install
npm run dev
```

יש להחיל את הקובץ `drizzle/0000_polite_devos.sql` על מסד D1 לפני הפעלת ההצבעה. כאשר הרשימות הסופיות יתקבלו, יש להזין אלבומים לטבלת `albums`, שירים לטבלת `songs` וזמרים לטבלת `artists`.

שירות הטלפון דורש `SITE_API_BASE_URL` ומופעל בנפרד מתוך `ivr-service/`.

## קריינות התפריטים בקו

כל תפריט הצבעה רציף מוקלט בקובץ אחד: כל האלבומים, כל הזמרים, וכל השירים של כל אלבום. ברשימה של יותר מתשעה פריטים הקו משתמש בקודים באורך קבוע, לדוגמה `01` עד `50`, כדי שהקשה על הספרה הראשונה לא תמתין ל־timeout. תפריטי הניהול בקו ההקלטות אינם קריינות רציפה ולכן הם נשארים בעמודים של עד שמונה אפשרויות, עם הספרה `9` להמשך.

# ראש בראש

מערכת הצבעה למצעד מוזיקה, עם אתר ציבורי וקו טלפוני של ימות המשיח המשתמשים באותו מסד נתונים.

## תהליך ההצבעה

1. בחירת חמישה אלבומים.
2. בחירת שיר אחד מכל אלבום שנבחר.
3. בחירת זמר אחד עד שלושה.
4. אישור ושמירת הצבעה אחת לכל מזהה מצביע.

## רכיבים

- `app/` — אתר Next.js/Vinext ונתיבי API.
- `db/` ו־`drizzle/` — סכמת Cloudflare D1 והמיגרציה.
- `ivr-service/` — שירות Node.js רציף לקו ימות המשיח.

## פיתוח

```bash
npm install
npm run dev
```

אין צורך להחיל מיגרציות ביד: ה-deploy אינו מריץ אותן, ולכן בבקשה הראשונה `worker/schema-statements.js` בונה את הסכמה כולה על מסד D1 — טבלאות, עמודות חסרות, אינדקסים ושורות ברירת המחדל של `surveys` ו־`poll_settings`. כל המשפטים idempotent, כך שמסד קיים אינו משתנה ומסד ריק נבנה במלואו. הקבצים ב-`drizzle/` נשארים מקור האמת לסכמה עבור drizzle-kit. כאשר הרשימות הסופיות יתקבלו, יש להזין אלבומים לטבלת `albums`, שירים לטבלת `songs` וזמרים לטבלת `artists`.

כל משפט SQL שם רץ בנפרד דרך `prepare`, כי `D1Database.exec()` מפצל את הקלט לפי שורות ואינו יכול להריץ משפט הפרוס על כמה שורות. משפט שנכשל נרשם ללוג ואינו מונע את המשפטים שאחריו, והבקשה הבאה תנסה שוב.

שירות הטלפון דורש `SITE_API_BASE_URL` ומופעל בנפרד מתוך `ivr-service/`.

## קריינות התפריטים בקו

כל תפריט הצבעה רציף מוקלט בקובץ אחד: כל האלבומים, כל הזמרים, וכל השירים של כל אלבום. ברשימה של יותר מתשעה פריטים הקו משתמש בקודים באורך קבוע, לדוגמה `01` עד `50`, כדי שהקשה על הספרה הראשונה לא תמתין ל־timeout. גם תפריטי הניהול בקו ההקלטות מושמעים כרשימה אחת ללא עמודים: אפשרויות ארוכות נבחרות בקודים כמו `01`–`15`, והקוד `00` מחזיר לתפריט הראשי.

## ניהול טלפוני

השלוחה `/recordings` היא קו ניהול למספרים מורשים. אפשר להקליט, להשמיע, להחליף ולמחוק קריינויות; לפתוח ולסגור הצבעה; ליצור, למחוק ולהפעיל סקרים; לשנות שלבים וכמויות; להפעיל, להשבית, לסדר ולמחוק אלבומים, שירים וזמרים; לאשר או להסיר מספרי מקליטים; ליצור, לשחזר ולמחוק גיבויים מלאים; לאפס הצבעות; ולשמוע מצב ותוצאות. הכניסה מבוססת על זיהוי המספר, וכל העלאת הקלטה ופעולת ניהול נבדקת שוב מול הרשימה המאושרת באתר. אי אפשר להסיר במהלך שיחה את המספר שממנו מנהלים או את המספר המורשה האחרון. פעולות שמחייבות קובץ או טקסט חופשי, כמו העלאת שירים, עטיפות וכתובות מנהלים, נשארות באתר.

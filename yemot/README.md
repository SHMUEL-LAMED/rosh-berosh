# מערכת ימות המשיח — המצעד השנתי

התיקייה משקפת את מבנה השלוחות המתוכנן במערכת IVR2 מספר 0737053751.

## תפריט ראשי

- 1 — הצבעה למצעד
- 2 — האזנה למועמדים
- 3 — תוצאות ועדכונים
- 4 — תגובות והקדשות
- 5 — תקנון המצעד
- 9 — כניסה לניהול

## לפני העלאה למערכת

1. מחליפים את שלוחות הקטגוריות והמועמדים בהתאם לרשימה הסופית.
2. מקליטים ומעלים את הודעות M1000 לכל תפריט.
3. מוסיפים מנגנון סנכרון מרכזי ומניעת הצבעה כפולה.
4. שומרים את טוקן ימות המשיח רק במשתנה סביבה — לעולם לא במאגר.

הקבצים כאן הם שלד בטוח לגרסה הראשונה.
